# Actividades JS - Clase 8 WEB

Este repositorio contiene la resolución práctica de los ejercicios de JavaScript correspondientes a la **Séptima Semana (Clase 8)**. El objetivo principal de la actividad es afianzar los conceptos fundamentales del lenguaje, tales como tipos de datos, manipulación de estructuras, control de flujos y modularización con funciones.

Adicionalmente, se optó por implementar un **enfoque interactivo**, vinculando dinámicamente los scripts con la interfaz del archivo `index.html` mediante la manipulación del DOM para visualizar los resultados en tiempo real en el navegador, reemplazando las ventanas flotantes estáticas por flujos controlados.
